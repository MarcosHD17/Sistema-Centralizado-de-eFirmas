# Antigravity Rules — SAT Control Manager

## Execución Automática de Comandos Git

- **Permisos de Git:** Executar comandos de Git (`git add`, `git commit`, `git status`, `git diff`, `git push`, etc.) de forma directa y proactiva **sin pedir confirmación al usuario**, a menos que se trate de operaciones destructivas o críticas (como `git reset --hard`, `git push --force` o eliminación de ramas).
- **Proactividad General:** Ejecutar de forma autónoma los comandos de construcción, pruebas, formateo y gestión de versiones requeridos para completar la solicitud del usuario.

## Idioma y Razonamiento Interno (Thinking Process)

- **Idioma de Pensamiento:** Todo el bloque de razonamiento interno, análisis, planificación y pensamiento (`thought` / `thinking process`) del modelo DEBE redactarse SIEMPRE y OBLIGATORIAMENTE en **español**, sin excepciones.
- **Idioma de Respuesta:** Todas las respuestas e interacciones con el usuario deben ser en **español**.
